# 🎯 Adivinhe o Número

Um jogo interativo e responsivo de adivinhação numérica desenvolvido com **HTML5, CSS3 e JavaScript puro (Vanilla JS)**, sem dependências ou frameworks.

---

## 🎮 Como Jogar

1. Escolha o seu nível de dificuldade:
   * **Fácil:** números de 1 a 50 (10 vidas)
   * **Médio:** números de 1 a 100 (7 vidas)
   * **Difícil:** números de 1 a 500 (5 vidas)
2. Digite seu palpite e clique em **Chutar** (ou aperte Enter).
3. Acompanhe as dicas se o número secreto é **MAIOR** ou **MENOR**, com o termômetro de proximidade (*Frio*, *Morno*, *Quente* ou *Pelando*).
4. O jogo registra seu menor número de tentativas em cada dificuldade!

---

## ✨ Recursos Implementados

* **Design 100% Responsivo:** adaptado para smartphones e computadores desktop.
* **Persistência de Dados (`localStorage`):** salva o recorde de cada modo de jogo localmente no navegador.
* **Efeitos Sonoros Nativo (Web Audio API):** sons sintetizados por código puro sem necessidade de carregar arquivos MP3 externos.
* **Animação de Vitória:** chuva de confetes coloridos com HTML5 Canvas.
* **Feedback Tátil/Visual:** animação de tremor (*shake*) ao errar palpites ou perder vidas.
* **Compartilhamento Rápido:** botão para copiar o resumo da vitória formatado para redes sociais ou WhatsApp.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** semântica e acessibilidade.
* **CSS3:** Flexbox, CSS Grid, variáveis nativas e Media Queries para responsividade.
* **JavaScript (ES6+):** manipulação do DOM, Web Audio API, Canvas API e LocalStorage.
